## 回答一道工程题的四层结构

1. **定义**：先用一句话说明概念解决什么问题。
2. **原理**：解释核心流程、数据结构或协议机制。
3. **取舍**：说明它的限制，以及和替代方案的差异。
4. **实践**：结合真实场景说明配置、排错或优化方法。

例如回答“Redis 为什么快”时，不要停留在“因为在内存中”。还应覆盖事件循环、I/O 多路复用、命令执行模型，以及大 Key、慢命令为什么仍然可能阻塞主线程。
