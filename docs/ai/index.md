# AI Agent 学习路线

这一部分正在建设中。它不会成为零散名词的集合，而会延续本站的组织方式：从模型输入输出开始，逐步走到可观测、可评估、可安全执行的 Agent 系统。

## 计划中的四个阶段

### 01 · LLM 应用基础

模型 API、结构化输出、Tool Calling、Prompt 与上下文窗口。

### 02 · RAG 与知识系统

文档解析、Chunk、Embedding、混合召回、重排、引用与评估。

### 03 · Agent Runtime

Agent Loop、工具系统、状态、记忆、任务、权限、沙箱与恢复机制。

### 04 · 工程化与评估

Tracing、数据集、离线评估、线上指标、成本、延迟和失败恢复。

在内容上线前，可以先从[完整后端路线](/fullstack/)开始学习。
