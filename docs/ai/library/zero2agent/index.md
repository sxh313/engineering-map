# zero2Agent 工程课程

本课程收录 `ranxi2001/zero2Agent` 在固定基线 `79f7f91` 中的中文学习材料、配图与项目章节。所有课程页面都在本站提供，阅读过程不需要打开原仓库。

## 课程模块

- [Agent 基础与原理](./learn-agent-basic/)：概念边界、Agent Loop、上下文、工具、记忆、评估和多 Agent。
- [LangGraph](./learn-langgraph/)：状态图、节点、边、条件分支、并行和模型接入。
- [SDK 与框架选型](./learn-sdk-frameworks/)：OpenAI、Google、Anthropic SDK 与对比。
- [框架调研](./learn-agent-survey/)：主流 Agent 框架的架构与适用场景。
- [OpenClaw](./learn-openclaw/)：Gateway、工具、记忆、RAG 与多 Agent。
- [Claude Code](./learn-claude-code/)：从 Agent Loop 到任务系统、Skills、后台任务与团队协作。
- [DeepSeek Harness](./learn-deepseek-harness/)：Harness、运行时、工具管线、上下文压缩、安全与 Subagent。
- [Agent 训练](./learn-agent-training/)：SFT、RL、数据混合、评估、部署和训练环境。
- [Agent 实践](./learn-agent-practice/)：个人主页、AI Coding 面试、开发工作流、Harness、Eval 和 RSI 实践。
- [Pi Coding Agent](./learn-pi/)：Provider、扩展、MCP、安全与 Session Runtime。
- [Codex](./learn-codex/)：配置权限、沙箱、MCP、SDK 和工程对比。
- [Agent 面试专题](./learn-agent-interview/)：17 个面试考察主题；该部分独立遵守 CC BY-NC-SA 4.0。
- [OfferPilot 生产级项目](./final-project/)：从产品需求、架构和检索到权限、语音、部署与 Web UI。
- [Agent API Lab 示例](./examples/agent-api-lab/)：消息协议、工具调用、上下文消融和流式协议的可运行练习。
