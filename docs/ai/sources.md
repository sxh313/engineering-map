# 来源、许可与引用说明

AI Agent 综合学习路线提供两种站内阅读方式：一套重新编排的融合路线，以及两套按原课程结构收录的阅读资料。原理讲解、工程拆解、表格、配图和项目章节都可以从本站打开。

日常学习入口全部留在本站。许可证允许且来源明确的正文、代码、表格或图示可以在保留署名后改编；来源不清的第三方截图与素材不直接复制。

## 本站采用的引用方式

1. **技术事实与概念**：使用本站自己的语言重新解释，并映射到站内手册章节。
2. **短引用**：使用引用格式，紧邻标注作者、项目、固定版本和章节。
3. **代码改编**：在代码块前说明来源项目、原始许可和主要修改。
4. **图表与表格**：优先重新绘制；直接复用时标注项目、作者、版本和许可。
5. **题库**：单独遵守 CC BY-NC-SA 4.0，不与其他许可内容混淆。

## 融合路线与原资料如何配合

原资料分别保留在[AI Agent Book 站内全书](./library/ai-agent-book/)和[zero2Agent 站内工程课程](./library/zero2agent/)。它们用于完整阅读原章节、原始例子和配套图表。

融合路线则负责把重叠内容按先修关系组织起来，并补充个人学习顺序、实践任务和验收证据。你可以先读融合手册建立结构，再按目录进入原章节深读；两种入口都留在本站。

外部网页引用会保留为不可点击的来源文字，避免从课程阅读入口离站；命令、示例代码、API 地址和配置内容仍保留其原始技术用途。

## 内容边界

以下内容属于本站原创：

- 三条学习路径、十阶段顺序和 133 篇内容映射。
- 每阶段的核心问题、动手任务、失败条件和验收证据。
- 页面交互、视觉设计和 Agent Loop Trace。
- 后续基于个人实验形成的笔记、代码和复盘。

以下内容仍属于各自原作者或权利人：

- 上游仓库正文、代码、图表、PDF、EPUB、题库和品牌标识。
- 上游项目引用的其他第三方材料。

## 更新与勘误

上游仓库会持续变化。固定基线用于说明本站融合时参考的具体版本；更新时先比较目录、许可证与内容差异，再决定是否纳入本站。

如果发现署名、许可或来源说明不准确，请在 `sxh313/engineering-map` 仓库提交 Issue。本站会优先修正版权与来源问题。
