# 来源、许可与引用说明

AI Agent 综合学习路线是本站原创设计的学习结构、任务和验收契约，不是上游项目的镜像、翻版或合订本。

本站使用公开资料理解技术事实与设计思想，然后重新组织为适合个人学习和项目验证的路径。上游正文、原始图表、PDF 和完整题库仍应在原作者页面阅读。

## 本站采用的引用方式

1. **技术事实与概念**：使用本站自己的语言重新解释，并在对应阶段给出深读链接。
2. **短引用**：使用引用格式，紧邻标注作者、项目和原文链接。
3. **代码改编**：如果未来出现，会在文件头说明来源、原始许可和主要修改。
4. **图表**：默认重新绘制；若确需使用原图，先核对该文件的具体许可并保留署名。
5. **题库**：本站题目必须独立编写或来自已有后端课程，不复制受单独许可约束的完整题库。

## 为什么不直接合并正文

直接合并会同时带来三个问题：

- 学习顺序仍由原项目目录决定，无法围绕你的目标重新组织。
- 同一概念会重复出现，却缺少统一的任务和验收标准。
- 不同文件可能适用不同许可证，长期维护和商业边界容易混乱。

因此本站只融合“知识关系”和“学习方法”，不融合上游文件本身。

## 内容边界

以下内容属于本站原创：

- 三条学习路径与十阶段顺序。
- 每阶段的核心问题、动手任务、失败条件和验收证据。
- 页面交互、视觉设计和 Agent Loop Trace。
- 后续基于个人实验形成的笔记、代码和复盘。

以下内容仍属于各自原作者或权利人：

- 上游仓库正文、代码、图表、PDF、EPUB、题库和品牌标识。
- 上游项目引用的其他第三方材料。

## 更新与勘误

上游仓库会持续变化。固定基线用于说明本站设计时参考的具体版本；页面中的“原理深读”和“工程深读”优先链接到固定提交，避免内容无提示漂移。

如果发现署名、许可或来源说明不准确，请在 [engineering-map 仓库](https://github.com/sxh313/engineering-map/issues) 提交 Issue。本站会优先修正版权与来源问题。
